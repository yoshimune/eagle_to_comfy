# Eagle to ComfyUI

Eagle **4.0.0 / Windows** 用のインスペクタ拡張です。ユーザー作成の `comfyui_png_provenance` が保存した PNG を単一選択すると、埋め込まれた `Description` と **Build ComfyUI Workflow** ボタンを表示します。

標準 ComfyUI の `prompt` / `workflow` だけを持つ PNG は対象外です。このプラグインは ComfyUI 本体に含まれない独自 API を使用します。

## 前提
- ComfyUIにカスタムノード "[comfyui_png_provenance](https://github.com/yoshimune/comfyui_png_provenance)" の導入が必要です
- Webブラウザ版のComfyUIを使用する必要があります

## 導入

1. ComfyUI に `comfyui_png_provenance` を導入して再起動し、ブラウザーを再読み込みします。`Save Image with Provenance` で保存した元の PNG を使用してください。
2. Eagle のプラグインメニューから「開発者オプション」を開き、ローカルプラグインのインポート機能で、この `manifest.json` があるフォルダーを選びます。開発プラグインのメニュー表記は Eagle の言語・build により異なります。
3. Eagle に元 PNG を取り込み、単一選択します。インスペクタにプラグインが表示されます。画像最適化などでメタデータが消えたファイルでは動作しません。

インスペクタ拡張は Eagle 4.0 Beta 17 以降の機能です。実際のインスペクタ登録・再表示・ホスト枠の表示は対象 build で確認してください。通常 PNG ではプラグイン内容を隠しますが、Eagle が確保する空の枠を完全に消すことは保証しません。

## 設定と操作

- インスペクタ内の **プラグイン設定**で基本 URL とタイムアウト秒数を保存します。初期値は `http://127.0.0.1:8188` と **30 秒**です。
- 設定は `%APPDATA%\eagle-to-comfy\settings.json` に保存します。Eagle ライブラリや元画像には書き込みません。
- **この画像の接続先**で基本 URL を一時上書きできます。空欄または「基本設定を使用」で復帰し、画像・ライブラリを変更すると上書きは解除されます。タイムアウトは基本設定を使用します。
- HTTP(S) URL のベースパスに対応します。URL 内の認証情報・query・fragment は指定できません。認証ヘッダーや資格情報の管理には対応していません。
- 接続一覧が 1 件なら反映先を自動選択し、複数なら選択欄で指定します。0 件なら ComfyUI のブラウザーを開き、フロントエンド拡張を読み込んで「接続一覧を更新」を押してください。
- キャンバスの既存グラフは事前に保存し、**Build ComfyUI Workflow** を押します。PNG が指定先へ送られ、埋め込み入力画像の展開と上流グラフの構築は ComfyUI 側の拡張が行います。生成キューには追加しません。

選択を追跡するため、表示中は公開 API `eagle.item.getSelected()` を 500 ms 間隔で確認します。複数選択時は非表示です。長文 Description は改行を保持した読み取り専用テキストとして表示し、HTML として解釈しません。

## API と表示状態

`GET /provenance/clients` で登録済みブラウザーを取得し、実行前に再確認します。`POST /provenance/restore` に multipart の `image` と `client_id` を送ります。ブラウザー登録と WebSocket は ComfyUI 拡張の責務です。

接続一覧 GET と復元 POST の状況は別々に表示します。入力・画像・反映先の確認に失敗した場合、復元 API は「未呼び出し」です。リクエスト開始時は「呼び出し開始・送信中」であり、サーバー受信を保証しません。

HTTP ステータスとエラーは表示しますが、復元結果の prompt・画像配置一覧などは表示しません。**HTTP 成功でもブラウザー上の構築完了は未確認です。** ブラウザーでの読み込み失敗・手動画像選択の警告は ComfyUI 側で確認してください。

タイムアウトは各 GET / POST の要求全体に適用します。タイムアウト・通信切断でも、サーバーでは復元が進んでいる場合があります。POST の自動再試行はしません。再実行すると新しい復元フォルダーが作られるため、先に ComfyUI 画面を確認してください。通知失敗の HTTP 409 でも配置済み入力画像が残る場合があります。

## 制限と安全性

- 独自 `comfyui-png-provenance/1` の PNG のみ対応します。WebP / JPEG、未知版、圧縮 Description は対象外です。
- 表示用メタデータは各チャンク **4 MiB** までです。超過時は明示エラーになります。
- PNG の識別情報・テキスト CRC を確認しますが、大きい IDAT / cpRV は読み飛ばします。ZIP・manifest・全チャンク CRC・アセット SHA-256 の完全検証は復元 API が行います。表示できることだけでは復元可能性を保証しません。
- 元 PNG と、そこに含まれる入力画像・メタデータを送信します。**信頼できる ComfyUI 接続先だけを指定してください。** client_id は認証ではありません。無認証サーバーをインターネットへ公開しないでください。
- リダイレクトを自動追従せず、TLS 証明書の検証を無効化しません。API エラー応答は最大 1 MiB まで取得します。
- サーバー起動、モデル・カスタムノードの導入、生成の自動実行、ストア公開は行いません。

## 開発

ランタイム依存パッケージ・ビルドは不要です。Eagle の Chromium 107 / Node 16 に合わせた CommonJS と標準 API を使用します。

```powershell
npm test
npm run check
```

テストは PNG fixture、ローカル HTTP サーバー、Eagle / DOM のモックを使用し、Eagle のライブラリや ComfyUI input は変更しません。実際の Eagle インスペクタ内での動作と、接続先ブラウザーへのグラフ構築は別途実機確認が必要です。
